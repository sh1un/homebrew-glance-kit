# Homebrew tap for galance-kit

Install `galance-kit` with:

```sh
brew tap sh1un/glance-kit
brew trust sh1un/glance-kit
brew install --cask galance-kit
```

Upgrade to the latest published version with:

```sh
brew update
brew upgrade --cask galance-kit
```

The Cask downloads the Developer ID-signed and Apple-notarized release from this repository's [Releases](https://github.com/sh1un/homebrew-glance-kit/releases). The application source remains in the private `galance-kit` repository.
